# Pułkownik

Kalkulator osi otworów pod podpórki półek w boku szafki, jako aplikacja na Androida.

Każde wysłanie zmian na GitHub automatycznie buduje plik `otwory-na-polki.apk`
i publikuje go w zakładce **Releases** (wydanie „najnowsza”).

Sam kalkulator to plik `app/src/main/assets/index.html`. Żeby go zmienić,
podmień ten plik i wyślij zmiany. APK zbuduje się ponownie.
